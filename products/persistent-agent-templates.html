Persistent Agent Templates Pack

Build AI agents that do not fall apart after reset.

Most AI agents are not persistent. They are long prompts pretending to remember.

They sound coherent while the context is warm — then fail after reset, model switch, stale memory, tool failure, or handoff.

The Persistent Agent Templates Pack gives builders reusable Markdown templates for designing agents with operational continuity: identity, memory, permissions, recovery, evidence, and correction paths.

What You Get
Core Identity Template
Define role, purpose, truth hierarchy, tone, non-goals, uncertainty behavior, and correction handling.
Memory Policy Template
Separate durable memory from raw logs, stale state, summaries, and temporary task progress.
Permission Boundary Template
Gate money, messages, public posts, destructive actions, sensitive data, credentials, and external operations.
Recovery Protocol Template
Define what a fresh session must load, verify, and admit before it acts.
Evidence Gates Template
Stop marking work as done without proof: paths, URLs, tests, logs, diffs, or verified outputs.
Agent Profile Examples + Checklist
Example profiles for assistants, analysts, writing partners, automation operators, and content/community agents.
Who It Is For

Good fit

Indie hackers, automation consultants, custom GPT/Claude Project builders, n8n/LangGraph/CrewAI users, local-agent builders, and teams whose agent works in demo but gets messy in real use.

Not for

Jailbreaks, spam bots, proof-of-consciousness claims, legal/security/compliance certification, or anyone looking for a magic prompt instead of operating structure.

Why This Matters

A vector database is not memory. A persona is not continuity. A long prompt is not recovery.

Continuity means the right constraints, corrections, permissions, and commitments survive interruption.
